# iPhone App Store screenshot shot list

Capture these only after signed-device QA passes. Use one dedicated synthetic account, reviewed output, and the same visual story across all frames. Do not show customer data, personal email addresses, debug UI, loading failures, or unreviewed AI output.

## Required 6.9-inch iPhone set

1. **Home** — clean signed-in home screen with the core value visible.
2. **Review your pantry** — synthetic fridge/pantry photos plus a corrected ingredient draft before confirmation.
3. **Fresh recipe** — a complete reviewed recipe with useful ingredients and instructions visible.
4. **Saved recipes** — several polished synthetic recipes demonstrating organization.
5. **Meal plan** — a populated plan using the same synthetic recipes.
6. **Offline shopping** — a shopping list with several checked and unchecked items; avoid showing a network error.

## Capture rules

- Portrait orientation at an accepted 6.9-inch size.
- Keep the status bar clean and consistent.
- Use high-contrast text and the production app icon/branding.
- Confirm spelling, truncation, safe areas, and Dynamic Type at the normal screenshot size.
- Do not add marketing claims that cannot be verified from the app.
- A separate 6.5-inch set is unnecessary when the accepted 6.9-inch set is supplied.
